# Personal Portfolio Website

My personal portfolio website, built with HTML, CSS, and JavaScript.

The website showcases my background, software development work, technical interests, projects, and contact information.

## 🌐 Live Website

**https://philacoding.github.io/Personal_Portfolio_Website/**

## 📋 About the Project

This repository contains the source code for my personal developer portfolio.

The website was originally created as a personal portfolio and is being developed further as part of my ongoing software engineering journey.

The project is intentionally built with core web technologies so that the structure, styling, and behaviour can be developed and maintained without relying on a large framework.

## 🚀 Running the Website Locally

Clone the repository:

```bash
git clone https://github.com/PHILACODING/Personal_Portfolio_Website.git
```

Move into the project directory:

```bash
cd Personal_Portfolio_Website
```

Open `index.html` in a web browser.

Alternatively, open the project in Visual Studio Code and use a local development server such as Live Server.

## 🌍 Deployment

The website is deployed using **GitHub Pages**.

The `master` branch is used as the publishing source, with the website files located in the repository root.

GitHub Pages provides free hosting for this public static website.

## 🔄 Development Workflow

Development is managed using Git and GitHub.

```text
Local Development
       ↓
Git
       ↓
GitHub Repository
       ↓
GitHub Pages
       ↓
Live Website
```

Changes are developed locally, committed to Git, and pushed to GitHub.
